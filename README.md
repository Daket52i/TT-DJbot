# djbot — радио и ТВ-бот для TeamTalk 5

**djbot** — форк проекта [teamtalk-universal-plugin](https://github.com/zolo-kirill/teamtalk-universal-plugin) от zolo-kirill, доработанный для удобной установки на любой TeamTalk 5 сервер.

Бот играет музыку, радио и телевидение в голосовой канал — без звуковой карты, через ffmpeg напрямую в TeamTalk.

---

## ✨ Возможности

- 🎵 Воспроизведение YouTube, Яндекс.Музыки, Музофонда, Rutube, прямых ссылок
- 📻 Более 1100 радиостанций (плейлисты `.m3u` в папке `radio/`)
- 📺 ТВ-каналы с видео и звуком через mediafile-поток TeamTalk (`/tv`)
- 📋 Очередь треков, избранное, перемотка, громкость
- 🔊 Единая громкость `/v` для радио, музыки и ТВ
- 💬 Реле сообщений и уведомлений в Telegram
- 👥 Регистрация новых учёток через Telegram-бота
- 🛡️ Защита от ботнетов (ник, мат, гео, всплески входов)
- 🔔 Уведомления о входах/выходах, изменениях прав учёток
- 📁 Воспроизведение файлов с диска (`/lf`)
- 🔄 Автоперезапуск каждую ночь в 03:00

## 🚀 Быстрая установка

```bash
git clone https://github.com/Daket52i/TT-DJbot.git
cd TT-DJbot
sudo ./install.sh
```

Скрипт спросит:
- **Host** — адрес TeamTalk сервера
- **TCP/UDP порты**
- **Никнейм** бота
- **Username и пароль** учётной записи
- **Канал** и пароль канала
- **Telegram токен** и ID (опционально)

## 🎵 Команды управления

| Команда | Описание |

| `/play <запрос или ссылка>` | Найти и воспроизвести |

| `/v <1-100>` | Громкость радио и ТВ (`/v 2` — это 2%, не «уровень 2») |
| `/sf 30` / `/sf -30` | Перемотка вперёд/назад (сек) |
| `/playlist` | Текущий плейлист |

| `/radio l <стр>` | Страница списка радиостанций |
| `/radio <номер>` | Запустить станцию по номеру |
| `/radio <текст>` | Поиск станции по названию |
| `/tv` | ТВ-каналы, страница 1 |
| `/tv l <стр>` | Страница списка ТВ-каналов |
| `/tv <номер>` | Включить ТВ-канал |
| `/tv <текст>` | Поиск ТВ-канала |
| `/tv stop` | Остановить ТВ |
| `/mow` | Моя волна Яндекс.Музыки |
| `/pop` | Случайная популярная музыка (шансон/поп/рок) с Музофонда |
| `/settings` | Показать все настройки (секреты маскируются) |
| `/set <ключ> <значение>` | Изменить настройку (работает в TG и TT) |
| `/welcome <текст>` | Задать приветствие сервера |
| `/sv yt` \| `ym` \| `mz` | Выбор сервиса: YouTube / Яндекс.Музыка / Музофонд |
| `/fav` | Избранное (`/fav +` — добавить) |
| `/dl` | Скачать текущий трек |
| `/vo` | Озвучивать название трека |

## 🛠 Настройка через Telegram и TeamTalk

Все настройки можно менять прямо из чата (владелец/админы):

- `/settings` — показать текущие настройки (токены и пароли замаскированы).
- `/set <ключ> <значение>` — изменить настройку.
- `/welcome <текст>` — быстрый способ задать приветствие (это `/set welcome <текст>`).

Примеры:

```
/set ym <OAuth-токен Яндекс.Музыки>     # включит /mow (Моя волна)
/set welcome Добро пожаловать! Правила в описании канала.
/set channel /music                     # перейти в другой канал TeamTalk (и запомнить)
/set server.host tt.example.com         # другой сервер (применится после /rs)
/set server.tcp_port 10333
/set server.nickname djbot
/set playback.default_volume 50         # громкость по умолчанию
/set welcome.enabled off                # выключить приветствие
```

После смены `server.host`, портов, логина или пароля нужно перезапустить бота: `/rs`.
Смена канала (`/set channel`) применяется сразу.

## ⚙️ Конфигурация

После установки конфиг лежит в `/opt/djbot/config.json`.

Основные секции:

```json
{
  "server": {
    "host": "ВАШ_ХОСТ",
    "tcp_port": 10333,
    "udp_port": 10333,
    "nickname": "djbot",
    "username": "music_bot",
    "password": "ВАШ_ПАРОЛЬ",
    "channel": "/"
  },
  "telegram": {
    "token": "ТОКЕН_БОТА",
    "owner_user_id": 123456789,
    "server_display_name": "Мой сервер"
  },
  "playback": {
    "default_volume": 50,
    "max_volume": 100
  },
  "radio": {
    "list_page": 15
  },
  "tv": {
    "video_bitrate": 512,
    "list_page": 20
  },
  "guard": {
    "enabled": true,
    "kick_empty_nick": false
  }
}
```

## 📻 Радиостанции

В комплекте **1113 станции**: авторские плейлисты, станции Волнореза и 1000 станций из открытого каталога [Radio Browser](https://www.radio-browser.info/).

Плейлисты `.m3u` лежат в папке `radio/`. Один файл может содержать одну или несколько станций:

```
#EXTM3U
#EXTINF:-1,Название станции 1
http://stream1.url/radio.mp3
#EXTINF:-1,Название станции 2
https://stream2.url/radio.aac
```

Добавляйте свои файлы и перезапускайте бота. Доступность внешних потоков зависит от вещателя.

## 📺 ТВ-каналы

В комплекте более 680 каналов (казанские, общероссийские и IPTV-org).

Плейлисты `.m3u` / `.m3u8` лежат в папке `tv/`. Бот объединяет их, убирает дубликаты по названию и сохраняет приоритетный порядок каналов.

```bash
/tv              # первая страница списка
/tv l 2          # вторая страница
/tv 1            # включить канал по номеру
/tv Первый       # поиск по названию
/tv stop         # остановить ТВ
```

ТВ передаётся как mediafile-поток TeamTalk: видео VP8 + звук. Для работы нужны права `USERRIGHT_TRANSMIT_MEDIAFILE_VIDEO` и `USERRIGHT_TRANSMIT_MEDIAFILE_AUDIO`. Если видеопоток не запустился, бот автоматически включает только звук этого канала.

Громкость ТВ регулируется той же командой `/v`, что и радио: бот применяет gain к mediafile-аудиопотоку.

## 🐛 Частые проблемы

| Симптом | Решение |
|---|---|
| Нет звука в канале | Проверь codec канала: Opus 48kHz |
| Бот не заходит в канал | Используй числовой ID вместо пути с кириллицей |
| YouTube не работает | Добавь куки в `services.yt.cookiefile_path` |
| Яндекс.Музыка не работает | Добавь токен в `services.ym.token` |
| ТВ идёт без видео | Проверь права mediafile video у учётки бота |
| ТВ очень тихий | `/v` задаёт проценты: попробуй `/v 50` или `/v 100` |
