# djbot — радио-бот для TeamTalk 5

**djbot** — форк проекта [teamtalk-universal-plugin](https://github.com/zolo-kirich/teamtalk-universal-plugin) от zolo-kirill, доработанный для удобной установки на любой TeamTalk 5 сервер.

Бот играет музыку и радио в голосовой канал — без звуковой карты, через ffmpeg напрямую в TeamTalk.

---

## ✨ Возможности

- 🎵 Воспроизведение YouTube, Яндекс.Музыки, Rutube, прямых ссылок
- 📻 Радиостанции (плейлисты `.m3u` в папке `radio/`)
- 📋 Очередь треков, избранное, перемотка, громкость
- 💬 Реле сообщений и уведомлений в Telegram
- 👥 Регистрация новых учёток через Telegram-бота
- 🛡️ Защита от ботнетов (ник, мат, гео, всплески входов)
- 🔔 Уведомления о входах/выходах, изменениях прав учёток
- 📁 Воспроизведение файлов с диска (`/lf`)
- 🔄 Автоперезапуск каждую ночь в 03:00

## 🚀 Быстрая установка

```bash
git clone https://github.com/Daket52i/TT-DJbot.git
cd TT-DJbot
sudo ./install.sh
```

Скрипт спросит:
- **Host** — адрес TeamTalk сервера
- **TCP/UDP порты**
- **Никнейм** бота
- **Username и пароль** учётной записи
- **Канал** и пароль канала
- **Telegram токен** и ID (опционально)

## 🎵 Команды управления музыкой

| Команда | Описание |
|---|---|
| `/play <запрос или ссылка>` | Найти и воспроизвести |
| `/stop` | Остановить |
| `/skip` | Пропустить трек |
| `/v <5-100>` | Громкость |
| `/sf 30` / `/sf -30` | Перемотка вперёд/назад (сек) |
| `/playlist` | Текущий плейлист |
| `/radio` | Список радиостанций |
| `/fav` | Избранное (`/fav +` — добавить) |
| `/dl` | Скачать текущий трек |
| `/vo` | Озвучивать название трека |

## ⚙️ Конфигурация

После установки конфиг лежит в `/opt/djbot/config.json`.

Основные секции:

```json
{
  "server": {
    "host": "ВАШ_ХОСТ",
    "tcp_port": 10333,
    "udp_port": 10333,
    "nickname": "djbot",
    "username": "music_bot",
    "password": "ВАШ_ПАРОЛЬ",
    "channel": "/"
  },
  "telegram": {
    "token": "ТОКЕН_БОТА",
    "owner_user_id": 123456789,
    "server_display_name": "Мой сервер"
  },
  "guard": {
    "enabled": true,
    "kick_empty_nick": false
  }
}
```

## 📻 Радиостанции

Плейлисты `.m3u` в папке `radio/`. Добавляйте свои:

```
#EXTM3U
#EXTINF:-1,Название станции
http://stream.url/radio.mp3
```

## 🐛 Частые проблемы

| Симптом | Решение |
|---|---|
| Нет звука в канале | Проверь codec канала: Opus 48kHz |
| Бот не заходит в канал | Используй числовой ID вместо пути с кириллицей |
| YouTube не работает | Добавь куки в `services.yt.cookiefile_path` |
| Яндекс.Музыка не работает | Добавь токен в `services.ym.token` |
